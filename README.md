# Oratorio Don Bosco Alessandria — app Android

Qui ci sono solo i file APK dell'app per lo staff dell'oratorio, uno per ogni versione (sezione **Releases**).
L'app li scarica e li installa da sola quando trovi l'avviso di aggiornamento.

Per usare l'app serve un account dell'oratorio. Il codice dell'app non è qui.
